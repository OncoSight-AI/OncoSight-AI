# OncoSight AI — Frontend

A React + Vite research workspace for medical-imaging machine-learning experiments.

## Technologies Used

- React.js
- Vite
- JavaScript
- CSS
- React Router
- Lucide React
- Recharts

## Installation

First, install Node.js.

Open the terminal inside the frontend folder.

Run:

npm install

## Start the development server

npm run dev

Open the localhost URL displayed in your terminal.

## Build the project

npm run build

## Project Features

1. Dashboard
2. Medical image upload interface
3. Image preview viewer
4. Results dashboard
5. Model performance charts
6. Study history
7. PDF report printing
8. About page
9. Settings page

## Backend Integration

The frontend can connect to a backend API.

Configure VITE_API_BASE_URL in your .env file.

The default demo mode uses sample records.

## Important Notice

validated clinical diagnoses or treatment recommendations.
